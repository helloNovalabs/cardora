# Comptes Cardora — plan

> Exécution : natif (l'utilisateur, débutant, a dit « vas-y »).

**Goal:** connexion par code e-mail et collection synchronisée entre appareils.
**Architecture:** `@supabase/supabase-js` ; une ligne `collections` par personne (jsonb) ; `store.ts` garde l'état local et appelle `sync.ts` après chaque `save`.
**Spec:** docs/superpowers/specs/2026-11-21-comptes-design.md

## Review Focus
- Connexion avec une collection locale non vide ET une collection en ligne non vide → union, aucune carte perdue.
- Hors ligne / erreur réseau → l'appli continue en local, la synchro réessaie au prochain changement.
- Code faux ou expiré → message clair en français.
- Déconnexion → la collection reste sur l'appareil (pas d'effacement surprise).
- Deux onglets → le dernier enregistrement gagne (accepté).

### Task 1 : table Supabase
- `supabase/001_collections.sql` : table `collections(user_id uuid primary key references auth.users on delete cascade, data jsonb not null, updated_at timestamptz default now())`, RLS + 3 policies (select/insert/update où `auth.uid() = user_id`). Exécuté dans l'éditeur SQL.
- Modèle d'e-mail « Magic Link » → affiche `{{ .Token }}`. URL du site = https://cardora-ecru.vercel.app.

### Task 2 : fusion (pure, testée)
- `src/lib/merge.ts` : `mergeStates(a: State, b: State): State` — par carte, qty = max ; `followed` = union (clé game+setId), ordre de `a` d'abord.
- Test `scripts/merge.test.ts` (node --experimental-strip-types) : carte seulement en local, seulement en ligne, des deux côtés (qty max), classeurs dédupliqués.

### Task 3 : synchro
- `src/lib/supabase.ts` (client, URL + clé publishable).
- `src/lib/sync.ts` : `startSync()` (session → charge la ligne, fusionne, enregistre), `pushSoon()` (enregistrement retardé 800 ms), `useAccount()` → `{ email, status: 'off'|'sync'|'ok'|'error' }`.
- `store.ts` : exporter `getState()`, `replaceState(s)`, et appeler `pushSoon()` dans `save`.

### Task 4 : page Mon compte
- `src/pages/Account.tsx` : e-mail → « Recevoir le code » → 6 chiffres → connecté (e-mail, état de synchro, Se déconnecter). Erreurs traduites.
- Route `/compte`, lien dans le menu et la barre du bas. Couleurs du thème.
- Vérif : `npx tsc -p tsconfig.app.json --noEmit`, `npm run build`, test réel sur le site en ligne.
